Chegado a um problema onde so conseguia implementar as operações beq de salto condicional neste processador single cycle.
Então inventei um modulo que recebe um funct3, a flag zero da alu, e a condição de branch vinda da control unit para conseguir defenir
uma pc_src que seja coerente com todos os tipos de branch conditions. Sendo assim adicionei na control_unit todos os tipos de branch
conditions e qual a operação que a alu devia fazer para cada uma. 
De acordo com a zero_flag produzida pela alu, o jump_module verifica se é a condição é aceite ou não.
Casa simples beq -> Se x1-x2 for igual a zero então pc_src tem de ser 1
             bne -> Se x1-x2 for diferente de zero então pc_src tem de ser 1
             blt -> Se x1<x2 então a ALU faz a operação SLT que mete result a 1 se x1<x2, logo a zero_flag será 0 caso seja para fazer a condição
                    mas se x1 nao for menor que x2 o result vai ser zero e a zero_flag vai ser 1
